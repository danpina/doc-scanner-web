Open-source notices

Doc Scanner · Last updated October 29, 2026

Doc Scanner is built mostly from its own code. This page lists the open-source software it includes, with the notices its licenses ask for.

The iPhone app

The iPhone app includes no third-party libraries. It is built on Apple's own frameworks (SwiftUI, UIKit, PDFKit, Vision, VisionKit, Core Image, Contacts and PhotosUI), which come with iOS.

This website

The website scanner includes these two libraries, served from this site and unchanged. Their license notices are also kept at the top of each file.
